# tugas-bu-galuh-pw1

Tugas Pemrograman Web 1 (Bu Galuh) — website statis, S1 Sistem Informasi Universitas Pamulang.

## Isi repo

- `index.html` — halaman utama website
- `images/` — aset gambar

## Cara jalanin

Buka `index.html` langsung di browser, atau serve folder ini dengan static server apa aja, misal:

```bash
python3 -m http.server
```

Terus buka `http://localhost:8000`.
